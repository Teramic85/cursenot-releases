# CurseNot releases

Downloads and update information for **CurseNot** — a real-time profanity
censor for your microphone (Discord, OBS, games).

- **Download:** see [Releases](../../releases).
- `manifest.json` (once published) is what the app's *Check for Updates*
  button reads. It is signed: the app verifies it against a public key built
  into CurseNot and ignores anything that doesn't verify, so this repo can't
  push a fake update even if it were compromised.

This repository contains no source code.
